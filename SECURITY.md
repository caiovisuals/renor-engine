# Security policy

## Reporting a vulnerability

Please report security issues privately through GitHub's private vulnerability reporting:

https://github.com/renorai/renor-engine/security/advisories/new

Do not open a public issue for vulnerabilities such as secret exposure, authentication or authorization bypass, unsafe network exposure, or data leaks.

Include, if you can:

- the affected version or commit;
- steps to reproduce;
- the impact, including whether note contents, memory facts or local file paths could be exposed.

## Supported versions

Security fixes land on the latest `main` branch only.
