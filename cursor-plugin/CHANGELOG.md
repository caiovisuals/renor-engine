# Changelog

All notable changes to this plugin will be documented here.

- Relicensed from AGPL-3.0-only to Apache-2.0, with the engine. No behaviour change.

- Added the `renor` MCP server pointing at `https://mcp.renor.cloud/mcp`.

- Added the `renor-memory` skill: when to recall before answering and what to save.
