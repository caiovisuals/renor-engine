# Upstream source

Renor's memory engine started from an open-source project:

- Upstream project: https://github.com/sterben-enec/obsidian-semantic-memory
- Imported snapshot: `eee47652e59738807129672a59c07d910beb65f9`

The upstream project is licensed under ISC. Its copyright notice is kept unchanged in [`NOTICE`](NOTICE). Renor's own work in this directory is licensed under AGPL-3.0-only ([`LICENSE`](LICENSE)). [`NOTICE`](NOTICE) also records the licenses of bundled third-party libraries.

The upstream project's original README, contributing guide and context notes are kept under [`docs/upstream/`](docs/upstream/) for provenance. [`docs/upstream/source-manifest.json`](docs/upstream/source-manifest.json) records the SHA-256 of each imported file at import time.

Renor's engine is maintained here, not upstream. To report a vulnerability in Renor, follow [`SECURITY.md`](SECURITY.md).
